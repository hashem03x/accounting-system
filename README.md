# Leopard

This is the front-end repository for Leopard E-commerce, a modern and responsive online shopping platform built using React, TypeScript, Vite, Tailwind CSS, and Mantine UI. The application supports multi-language functionality (Arabic and English) and includes features like product filtering, image galleries, cart management, and user authentication. Check out the [backend repository](https://github.com/leopardegy/accounting-system-server) and the [deployed website](https://leopardegy.com).
